# reflector-structural-dynamics
Physical derivations of the reflector ground station macro-structural response, vibration, and deformation using a reduced model. 
What's inside: symbolic derivations and simulations of ground station deformation from gravity and external excitation (i.e. wind); initial surface error estimations.
What's to be done: determining whether we can work out a minimum inertia required to achieve [X] maximum residual surface error RMS and use that parameter as a driving factor for the mechanical design of our dish's backplane structure.
